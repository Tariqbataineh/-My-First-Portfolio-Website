# Tariq Bataineh - Personal Portfolio Website

A modern and responsive personal portfolio website created to showcase my professional profile, technical skills, experience, certifications, and projects.

The portfolio was developed as part of my web development training journey at **Orange Coding Academy** using HTML, CSS, and Bootstrap.

## 🌐 Live Demo

You can view the portfolio directly in your browser without opening VS Code:

👉 **[View My Portfolio](https://my-portfolio-tariq.netlify.app/)**

## 📌 About The Project

This project is my personal portfolio website where I present my journey as a Computer Science graduate and Full Stack .NET Developer.

The website includes:

- Personal introduction
- About section
- Professional experience
- Certifications
- Technical skills
- Projects
- References
- Contact information

## ✨ Features

- Responsive design for Desktop, Tablet, and Mobile
- Responsive Bootstrap navigation bar
- Clean and modern UI
- Personal profile section
- Skills organized by technology category
- Certifications section
- Project showcase
- GitHub project links
